TER Projet Robotique
====================

Welcome to the official documentation of the TER Robotique project.

This documentation presents the installation process, the project architecture,
the software and hardware components, as well as the project management resources.

Project overview
----------------

The goal of this project is to design and develop a robotic system combining
software and hardware components.

The documentation is organized into several sections:

- Installation and setup
- Software architecture
- Hardware architecture
- Project management
- Technical resources and documentation
