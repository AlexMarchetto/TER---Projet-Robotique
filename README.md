# Projet TER - TP de robotique autonome avec Webots

## Présentation du projet

Ce dépôt contient le projet de Travail d’Étude et de Recherche (TER) réalisé dans le cadre du Master 1 Informatique et Cognition.

Le projet consiste à concevoir un travail pratique de robotique autonome à l’aide du simulateur Webots.  
Ce TP est destiné à des étudiants de licence informatique et permet de découvrir les bases de la robotique mobile autonome dans un environnement simulé, sans utiliser de matériel réel.

Le projet met à disposition un environnement Webots, un robot simulé, un contrôleur Java, ainsi qu’une documentation pédagogique permettant aux étudiants de comprendre, modifier et tester le comportement du robot.

## Objectifs du projet

L’objectif principal est de proposer un TP progressif, accessible et réutilisable permettant aux étudiants de :

- découvrir le fonctionnement du simulateur Webots ;
- manipuler un robot mobile autonome ;
- utiliser des capteurs virtuels comme la caméra et les capteurs de distance ;
- programmer des comportements autonomes en Java ;
- observer et analyser le comportement du robot dans un environnement simulé ;
- modifier progressivement un contrôleur existant ;
- comprendre les liens entre simulation, perception, décision et action.

## Description des dossiers

- `docs/` : documentation du projet et fichiers liés à ReadTheDocs.
- `src/` : code source principal du projet.
- `tpx` : fichiers liés au TP x.
- `.readthedocs.yaml` : configuration pour la génération de la documentation en ligne.
- `.gitignore` : fichiers et dossiers ignorés par Git.
- `README.md` : présentation générale du projet.

## Technologies utilisées

- **Webots** : simulateur de robotique.
- **Java** : langage utilisé pour programmer le contrôleur du robot.
- **Git / GitHub** : gestion de versions et hébergement du projet.
- **ReadTheDocs** : génération et publication de la documentation.
- **Sphinx** : outil utilisé pour structurer la documentation.

## Documentation

La documentation du projet est disponible dans le dossier `docs/`.

Elle contient les explications nécessaires pour comprendre l’organisation du projet, le fonctionnement du robot, les objectifs pédagogiques des TP et les différentes parties logicielles.
