# Projet TER – TP de robotique autonome avec Webots

## Présentation du projet

Ce dépôt contient le projet de Travail d’Étude et de Recherche (TER) réalisé dans le cadre du Master 1 Informatique et Cognition.  
Le projet consiste à concevoir un travail pratique (TP) de robotique autonome à l’aide du simulateur **Webots**.

Le TP est destiné à des étudiants de licence informatique. Il permet de découvrir les bases de la robotique mobile autonome à travers un environnement simulé, sans utiliser de matériel réel.

---

## Objectif du TER

L’objectif principal du projet est de proposer un TP clé en main permettant aux étudiants de :

- configurer un robot dans Webots,
- utiliser des capteurs virtuels (caméra, capteurs de distance),
- programmer des comportements autonomes en Java,
- observer et analyser le comportement d’un robot dans un environnement simulé.

Le TP est conçu pour être progressif, accessible et directement exploitable dans un cadre pédagogique.
