# Contribuer au projet

Merci de votre intérêt pour ce projet.

Ce document explique comment contribuer au dépôt, signaler un problème ou proposer une amélioration.

## Signaler un problème

Si vous trouvez un bug, une erreur dans la documentation ou un comportement incorrect du robot, vous pouvez ouvrir une issue sur le dépôt GitHub.

Merci d’indiquer autant que possible :

- une description claire du problème ;
- les étapes permettant de reproduire le problème ;
- le résultat attendu ;
- le résultat obtenu ;
- la version de Webots utilisée ;
- le système d’exploitation utilisé ;
- une capture d’écran ou un message d’erreur si nécessaire.

## Proposer une amélioration

Vous pouvez proposer une amélioration en ouvrant une issue.

L’amélioration peut concerner :

- le comportement du robot ;
- la structure du code ;
- la documentation ;
- les consignes des TP ;
- l’environnement Webots ;
- la correction d’erreurs ou d’incohérences.

Merci d’expliquer clairement :

- le besoin identifié ;
- la solution proposée ;
- l’intérêt de cette amélioration pour le projet ou les étudiants.

## Contribuer au code

Pour proposer une modification du code :

1. Créer une nouvelle branche depuis la branche principale.
2. Réaliser les modifications nécessaires.
3. Tester le projet dans Webots.
4. Vérifier que la documentation reste cohérente.
5. Créer une pull request vers la branche principale.
6. Décrire clairement les changements effectués.

## Nommage des branches

Il est conseillé d’utiliser des noms de branches explicites.

Exemples :

```txt
fix/detection-palets
feature/amelioration-controleur
docs/mise-a-jour-readme
tp1/nettoyage-code
